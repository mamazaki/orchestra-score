# 🎼 MaestroScroll — Orchestra & Band Score Studio

เว็บแอปพลิเคชันสำหรับ **เขียน อ่าน แยกพาร์ท และเลื่อนโน้ตเพลงอัตโนมัติ (Auto-Scroll)** สำหรับวงดุริยางค์ วงโยธวาทิต และวงดนตรีทุกรูปแบบ ออกแบบมาให้รันได้ทันทีบน **GitHub Pages** แบบ 100% Static Web App (ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องมีฐานข้อมูล) พร้อมรองรับการใช้งานแบบ Offline (PWA)

---

## ✨ ความสามารถหลัก

1. **🎼 สกอร์วงดุริยางค์ & แยกพาร์ท (Full Score & Parts)**
   - รองรับไฟล์ **MusicXML** (`.xml`, `.musicxml`, `.mxl`) ที่ส่งออกจาก MuseScore, Sibelius, Finale หรือ Dorico
   - กดสลับดูได้ทั้ง **Full Score (รวมทุกพาร์ท)** สำหรับวาทยกร หรือเลือกเฉพาะ **พาร์ทเครื่องดนตรีของตัวเอง** (เช่น Flute, Bb Clarinet, Bb Trumpet, Trombone, Tuba)
   - **Transpose Key อัตโนมัติ** รองรับเครื่องดนตรีกลุ่ม Concert Pitch, Bb, Eb, F Horn หรือปรับ ± Semitones เองได้
   - **เล่นเสียงจำลอง Multi-Instrument Synth** พร้อม Cursor วิ่งตามตัวโน้ต และ **Mixer แยกพาร์ท (Mute / Solo / Volume)** สำหรับฝึกซ้อม
   - สั่ง **พิมพ์เฉพาะพาร์ทที่เลือก** ออกมาเป็นกระดาษหรือ PDF ได้สวยสะอาด

2. **✍️ เขียนโน้ตเพลง (Score Composer)**
   - เขียนโน้ตเพลงหลายพาร์ทได้สดๆ บนเบราว์เซอร์ด้วยมาตรฐาน ABC Notation
   - มี **แถบเครื่องมือคลิกแทรกโน้ต (Quick-Insert Toolbar)** ทั้งตัวโน้ต เครื่องหมายแปลงเสียง ความยาวโน้ต เส้นกั้นห้อง และเครื่องหมายความดัง
   - แสดงผลโน้ตบรรทัด 5 เส้นแบบ Real-time พร้อมฟังเสียงและส่งออกเป็นไฟล์ `.abc` หรือ `.svg`

3. **📜 โหมดเวที & เลื่อนโน้ตอัตโนมัติ (Stage Auto-Scroll & PDF)**
   - เปิดไฟล์ **PDF สกอร์** หรือภาพสแกนโน้ตเพลง
   - **Auto-Scroll Engine** ปรับความเร็วตามพิกเซล/วินาที หรือคำนวณซิงค์จาก **BPM + จังหวะ + จำนวนห้องต่อหน้า**
   - มีโหมด **ขีดเขียนบนโน้ต (Stage Annotation)** ปากกา/ไฮไลต์/ยางลบ
   - รองรับแป้นเหยียบเปลี่ยนหน้าไร้สาย (**Bluetooth Page Turner Pedal**) ผ่าน `PageDown` / `PageUp` / `ArrowLeft` / `ArrowRight` / `Space`

4. **⏱️ เมโทรนอม & เครื่องตั้งสาย (Metronome & Tuner)**
   - เมโทรนอมความแม่นยำสูง (Web Audio API) พร้อมปุ่ม **Tap Tempo** และไฟกะพริบตามจังหวะ
   - เสียงอ้างอิงมาตรฐานวงดุริยางค์ (**Concert Bb4 = 466.16 Hz**, **Concert A4 = 440/442 Hz**, **Concert F4**)
   - **Tuner ตรวจจับเสียงจากไมโครโฟน** แสดงชื่อโน้ต ความถี่ (Hz) และเข็มวัด Cents (-50 ถึง +50)

5. **🗂️ คลังเพลง & เซ็ตลิสต์ (Setlist & Library)**
   - บันทึกโน้ตลงในเครื่องและจัดเรียงคิวเพลง (Setlist) สำหรับซ้อมหรือแสดงสด
   - ส่งออก/นำเข้าคลังเพลงเป็นไฟล์ `.json` เพื่อแชร์ให้สมาชิกในวงได้ง่ายๆ

## ⌨️ คีย์ลัดสำหรับซ้อม & แสดงสด

| ปุ่ม / แป้นเหยียบ | การทำงาน |
| :--- | :--- |
| `Space` | เล่น/หยุดเสียง หรือ เริ่ม/หยุด Auto-Scroll |
| `PageDown` / `ArrowRight` | เลื่อนลง / ไปหน้าถัดไป (ในโหมดเวที) |
| `PageUp` / `ArrowLeft` | เลื่อนขึ้น / ย้อนกลับหน้าก่อน |
| `M` | เปิด/ปิด เมโทรนอม |
| `F` | เปิด/ปิด โหมดเต็มจอ (Fullscreen) |
